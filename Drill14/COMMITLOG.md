Drill14: 새의 정확한 비행 애니메이션 구현 논리 상세 기록

1. 이미지 분석 및 프레임 순서
bird_animation.png는 918×506픽셀, 5열×3행 구조이다. 마지막 빈 칸을 제외한 14개 프레임을 왼쪽에서 오른쪽, 위에서 아래 순서로 재생한다. 0~13번을 순환하여 빈 칸에서 새가 사라지는 현상을 방지하고 원본의 날개 상승·하강 순서를 유지한다.

2. 정확한 클리핑 좌표
row, column = divmod(int(frame), 5)로 행과 열을 구한다. 이미지 크기가 행·열 개수로 나누어떨어지지 않으므로 각 경계를 round(column*image.w/5), round(row*image.h/3)으로 계산한다. 셀 폭은 183~184픽셀, 높이는 168~169픽셀이다. 정수 셀 크기를 반복해서 곱할 때의 누적 오차를 피한다. 위에서 계산한 bottom을 image.h-bottom으로 바꿔 pico2d의 왼쪽 아래 원점에 맞춘다. 출력 크기는 모든 프레임에 100×92를 적용한다.

3. 실제 시간에 따른 날갯짓
한 주기를 0.7초로 설정하여 FRAMES_PER_SECOND=14/0.7=20으로 계산한다. 매 update에서 frame=(frame+20*game_framework.frame_time)%14를 적용한다. frame은 소수로 보존하고 그릴 때만 int(frame)으로 바꾼다. 예를 들어 0.016초에는 0.32프레임 진행한다. 매번 정수로 변환하며 발생하는 소수 시간 손실을 막고 FPS와 관계없이 경과 시간에 맞춰 날갯짓한다. 지연이 길면 중간 그림이 생략될 수 있지만 재생 시간은 유지된다. 0.7초는 이번 구현에서 정한 재생 주기이다.

4. 일정한 비행 속도와 단위 변환
수업 방식대로 PIXEL_PER_METER=10/0.3을 사용한다. 기준 속도 30km/h에 1000/3600을 곱해 m/s로 변환하고 PIXEL_PER_METER를 곱해 약 277.78pixel/s로 바꾼다. 새마다 초기화 시 0.8~1.2배 속도를 정하여 약 222.22~333.33pixel/s를 유지한다. 이동식은 x+=dir*speed*frame_time이며 위치도 소수로 유지한다. 따라서 렌더링 횟수가 달라도 같은 시간이 지나면 같은 거리를 이동한다.

5. 방향에 맞는 반전과 연속성
원본 새는 오른쪽을 본다. dir=1이면 clip_draw, dir=-1이면 clip_composite_draw의 수평 반전 'h'를 사용한다. 회전 각도는 0이다. 이동과 부리 방향을 같은 dir 값으로 결정한다. 방향 전환 시 프레임을 초기화하거나 역순 재생하지 않아 진행 중인 날갯짓 위상이 유지된다.

6. 경계에서 이동 거리 보존
표시 폭 절반인 50과 canvas_width-50을 좌우 경계로 정하여 새 전체가 화면 안에 머물도록 한다. 오른쪽 초과 시 x=2*right-x와 dir=-1, 왼쪽 초과 시 x=2*left-x와 dir=1을 적용한다. 경계를 10픽셀 넘었으면 10픽셀 안쪽으로 반사한다. 경계에 고정하여 초과 이동량을 버리는 방식보다 경과 시간에 맞는 이동량을 보존한다. while로 반복하므로 한 프레임에 여러 번 왕복할 정도의 지연도 처리한다. 정확히 경계에 도착한 경우도 방향을 안쪽으로 지정한다.

7. 소년 위에서 독립적으로 비행하는 10마리
play_mode.init에서 Bird 10개를 생성하여 기존 game_world에 등록한다. x, y, frame, dir, speed는 각 인스턴스가 따로 보관한다. 시작 위치·높이·방향·속도·애니메이션 위상을 무작위로 정한다. frame은 0~14 범위의 소수 위상으로 시작한다. 무작위이므로 일부 새의 정수 프레임 그림이 같을 수 있지만 갱신 상태는 독립적이다. 이미지 리소스만 클래스 변수로 공유하여 한 번 로딩한다. 높이는 250~554로 설정한다. 새의 최저 하단은 250-46=204이고 기존 소년의 상단은 90+50=140이므로 소년 위에서 비행한다. y를 유지하며 x만 왕복 이동한다.

8. 수업 구조 통합 및 정상 종료
LEC16_Time/main.py 실행 시 Boy, Grass와 함께 새들이 표시된다. Bird.update()는 game_world의 인자 없는 호출 규약을 따르며 game_framework가 perf_counter 차이로 계산한 frame_time을 사용한다. draw()는 game_world.render에서 호출한다. ESC/SDL_QUIT 후에는 추가 갱신과 그리기를 중단한다. finish에서 월드를 비우고 main의 finally에서 캔버스를 닫는다. main은 수업 리소스 폴더로 작업 경로를 설정하고 종료 시 원래 경로를 복원한다.

9. 검증 결과와 범위
Python 문법 컴파일을 통과했다. 실제 pico2d 캔버스에서 원본 이미지 로딩, 14프레임 양방향 그리기, 소년과 새 10마리 렌더링을 실행했다. 개별 상태, 비행 높이, 좌우 경계를 확인했다. 기본 Bird 로직에서 1·4·20·100초를 한 번 또는 1000번으로 분할해 갱신한 위치·방향·위상이 허용 오차 내에서 일치했다. 통합 main 경로에서는 ESC/SDL_QUIT를 주입하여 종료와 월드 정리를 확인했다. 장시간 육안 관찰 대신 자동 실행으로 확인한 범위이다.
