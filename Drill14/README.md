# Drill #14 — 새의 비행 애니메이션

실행: 프로젝트 루트에서 `python Drill14/drill14.py`

필요 패키지: `python -m pip install pico2d`

ESC 또는 창 닫기로 종료합니다. 이미지 경로는 실행 위치에 관계없이 소스 파일 기준으로 찾습니다.

## 구현 원리

- 제공된 bird_animation.png는 918×506 픽셀입니다. 5열×3행의 격자에서 마지막 빈 칸을 제외한 14개 프레임을 왼쪽에서 오른쪽, 위에서 아래 순서로 사용합니다.
- 가로·세로 길이가 격자 개수로 나누어떨어지지 않으므로 경계 좌표를 각각 반올림합니다. 폭은 183~184, 높이는 168~169픽셀입니다. pico2d의 원점이 왼쪽 아래이므로 이미지 위쪽 기준 행 좌표를 변환합니다.
- `frame = (frame + (14 / 0.7) * frame_time) % 14`로 한 날갯짓 주기를 0.7초에 재생합니다. 소수 프레임을 유지하고 그릴 때만 정수로 변환하여 렌더링 횟수에 따라 날갯짓 속도가 바뀌지 않습니다.
- 원본 새는 오른쪽을 봅니다. 오른쪽 이동에는 clip_draw, 왼쪽에는 clip_composite_draw의 'h' 반전을 사용합니다. 두 방향에 같은 프레임 순서를 적용합니다.
- 수업 코드의 km/h → m/s → pixel/s 변환을 따릅니다. 기준 속도는 30km/h이며, 개체마다 0.8~1.2배 속도를 한 번 정하여 유지합니다. 이동량은 방향×초당 속도×frame_time입니다.
- 새의 표시 폭 절반을 경계 여백으로 둡니다. 경계를 넘으면 초과 거리만큼 반사하며, 긴 프레임에서 여러 번 왕복한 경우도 처리합니다. 따라서 이동 시간을 버리지 않고 새 전체가 화면 안에 머뭅니다.
- Bird 10개는 각자 시작 위치, 높이, 방향, 속도, 날갯짓 위상을 가집니다. 원본 이미지는 클래스 변수로 한 번만 로딩합니다.
- 수업의 Bird.update/draw 구조와 이벤트→갱신→그리기 루프를 따릅니다. try/finally에서 캔버스를 정리합니다.

## 확인 결과

- Python 문법 컴파일 통과.
- 실제 pico2d 캔버스와 원본 이미지 로딩 및 10마리 렌더링 실행 성공.
- 14개 프레임×양방향 그리기 및 클리핑 범위 확인.
- 1·4·20·100초를 한 번 또는 1,000번으로 나눈 업데이트에서 위치·방향·애니메이션 위상이 일치함을 확인.
- ESC 및 SDL_QUIT 이벤트를 main 루프에 주입하여 close_canvas 호출 확인.

원래 제공된 LEC16_Time 수업 파일은 수정하지 않았습니다.
